# pair-wise-yf-48 建筑设计竞赛匿名评审

源提示词摘要：主办方设置评分维度、权重和提交规则，评委在匿名状态下独立查看方案、打分、填写意见、声明利益冲突和保存草稿；系统提供提交进度、异常分处理、结果锁定与并列排名规则。

## 本地优先台账

针对「评委断网打分、回网后与主办方台账对不齐」的场景，评审台实现了本地优先（local-first）的台账：

- **断网照常评分**：评分维度、评审意见、利益冲突声明都先写本机（sessionStorage），提交进入本地待同步队列；刷新后草稿、队列、冲突和名次留档都还在。
- **联网合并**：恢复联网（或点「立即合并」）后，客户端把待同步队列按序并入主办方台账（`src/ledger/server.ts`，localStorage 模拟中心台账 + BroadcastChannel 跨标签页同步），并拉取最新台账。
- **冲突分**：以后到提交基于的台账版本号（baseRev）与当前版本比对，不一致即并发——后到的留为冲突分并标出差异（先到/后到分值与意见对照），不覆盖先到内容；未解决的冲突分不计入有效评委数。本人可「撤回后到评分」或「确认采用我的评分」。
- **锁定与留档**：全部方案齐备且冲突全部解决后才能锁定；锁定名次遇到评分改动或冲突确认即失效重算，历史名次留档可查。
- **幂等与越权**：提交请求号去重 + 队列合并 + 内容判重，重复点击只生成一条记录；评委只能改自己的评分，主办方锁定前看不到分值，越权提交/确认/锁定都会被拒绝并记入台账事件。

### 演示并发冲突

开两个标签页分别扮演「评委-林策」和「评委-周筑」：A 在「同步台账」页打开「模拟断网」后提交某方案，B 在线提交同一方案，A 再恢复联网合并——A 的后到评分即成为冲突分，可在页面中查看差异并确认。

## 技术栈

Vue3、TypeScript、Vite、Naive UI、Pinia、Vue Router、Axios、VueUse、VeeValidate、Zod、Vue I18n。

## 本地运行

```bash
npm install
npm run dev
npm run build
npm run smoke   # 台账合并/冲突/锁定/幂等/越权的冒烟测试
```
